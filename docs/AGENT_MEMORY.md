- **完整 PSD 图层参考（用户提供的指南，按遮挡顺序从前到后）**：
  1. 前景饰品：呆毛、帽子/发卡/眼镜、手持道具
  2. 前发：中、左、右、鬓角、发型高光
  3. 眼睛：眉毛、双眼皮线、上睫毛（主/外/内）、下睫毛、眼皮遮挡层、高光、瞳孔、眼白

  8. 躯干与衣服：领子/领带/蝴蝶结，外套前摆 L/R，外套后摆，胸部，上半身，下半身（上下交界要有重叠），裙子/裤子前后片
