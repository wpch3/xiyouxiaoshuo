## 自行查询的资料（会话 5，用户要求：六个项目没有办法时自己上网查）

眼睛（Live2D 官方与社区）：
- Live2D 官方 PSD 教程（docs.live2d.com/4.2 cubism-editor-tutorials/psd）：眼睛要分开睫毛、眼球、眼白；眼白可作为剪贴蒙版材料；眼白下方要保留被眼球遮住的部分，眼球移动时才不露缝。嘴作为蒙版也可以，但形变大时工时高，嘴线容易超出遮罩。
- Reddit r/Live2D（rrx1w0）：眼睛从上到下依次为上眼睑、下眼睑、虹膜、眼白；睫毛单独成层放在眼睑上方；高光放在虹膜上方；口腔内色要比嘴线大一圈，防止张嘴时露缝。
- Reddit r/Live2D（1mr9p6l）：Live2D 的多层蒙版嵌套不稳定。常用做法：眼白放在最上面裁剪虹膜，再反向蒙版得到虹膜形状的孔。
- 结论：我之前用“羽化肤色椭圆”做眼皮不是标准做法。正确做法是拆出上下眼睑层（与脸同色）、睫毛、眼白、虹膜、高光，眼球和眼白之间用剪贴蒙版。

骨骼与拆件（2D 骨骼通用流程）：
- drawphics.com（2026）：每个会动的部位独立成层（头、躯干、大臂、小臂、手、大腿、小腿、脚）；关节处要多画一截重叠（肩、肘、膝、髋），否则弯曲时会露出空白。
- Blender 2.5D 教程（arielbaron-robbins.com）：用 deform 骨骼链（躯干、手臂、腿、头），部件按层绑定，然后做权重。
- Adobe 资料：骨骼层级为 髋→大腿→小腿→脚，肩→大臂→小臂→手；旋转父骨骼时子骨骼跟随；肘、膝用 IK 保证方向。
- Skillshare（Animating With Character）：每只手有手、小臂、大臂三层；腿部可以合成一层不拆脚；先给关节放控制点（pin），再按父子关系生成骨骼。

对当前项目的意义：
- 小寻的身体要按上述规则拆：头、躯干、大臂、小臂、手、大腿、小腿、脚，关节处补重叠区域。
- 眼睛要按眼皮、眼白、虹膜的顺序拆，不再用程序画的眼皮椭圆。

学到的拆件规则：

- **嘴**：上唇线、下唇线、上牙、下牙、舌、口腔底色（比嘴线大一圈）。

- **脖子**：脖子单独成层，向上伸进头部，向下伸进胸腔。脖颈阴影单独。
- **躯干**：胸部 L/R、上半身、腰部/骨盆（上下交界有重叠补图）、外套/束身衣前片、后肩/披肩、裙子前后片、腰封/饰品、弯腰时的重叠区。
- **手臂**：泡泡袖/肩饰（可独立摆动）、大臂、小臂、手掌；肩、肘、腕处有补图。
- **腿**：大腿（根部要补图）、小腿、脚/鞋；膝、踝处有补图；腿部配饰单独。
- **尾巴**：分段（根部、中段关节、尾梢），每个关节处补图，正片叠底的阴影单独。
- **后景/背饰**：背部大蝴蝶结 L/R、披风后片、道具（手持、可交互）、地面阴影。

## 教程参考图学习要点（art/reference/tutorial_breakdown，8 张，用户提供）

注意：这些图是另一个紫色双马尾角色的拆件示例，不是小寻。只学“拆法和规则”，不照搬部件。

第1部分 头发：
- 前发/刘海（中）、左右侧发、呆毛单独成层；侧发/鬓角 L/R 要有“补图”（向下延伸到发根下面）。
- 马尾/辫子 L/R 分段，每个关节处有连接点，关节处要补图重叠。
- 后发要有完整补图（发际线之下、脖子后面）。
- 层序：前发 → 侧发 → 后发。发饰（发夹、蝴蝶结、发箍）单独成层。

第2部分 面部与五官：
- 眼睛：眉毛 L/R、双眼皮线、上睫毛、下睫毛、眼睑遮挡层（闭眼用，与脸同色）、高光 L/R、瞳孔 L/R、眼白 L/R（眼白作为底层遮罩，要画出眼球背后的部分）。
- 脸：脸底色完整绘制（补图），腮红、鼻子与鼻影单独成层，耳朵 L/R 单独成层。
- 嘴：上唇线、下唇线、上牙、下牙、舌头、口腔底色（比嘴线大一圈）。
- 对图：脸部用网格做对位（图中有“对图”标注网格，用于变形时对齐）。

第3部分 身体、躯干与脖子：
- 脖子：向上插进头里，向下插进胸口，需补图。
- 胸部 L/R、胸腔与上躯干、大面积补图。
- 领结/蝴蝶结、胸前配饰、外套/束身衣前片、后肩/披肩单独成层。
- 腰部/骨盆：上下半身交界要做“弯腰重叠区”，补图让上半身可以弯。
- 裙子前片与后片分开，腰封/饰带单独成层。

第4部分 四肢：
- 泡泡袖/肩饰可以独立做出来，做肩部和手臂的小动作。
- 大臂 L/R、小臂 L/R、手掌 L/R：关节处都要补图（肩补图、肘补图、腕补图、手掌）。
- 大腿 L/R（根部要补图，插进骨盆）、小腿 L/R（膝关节补图）、脚/鞋 L/R（踝关节补图）。
- 腿部配饰（袜子、绑带）单独成层。

第5部分 尾巴、后景与道具：
- 尾巴分段（根部、中段关节、尾梢），每段关节补图。
- 后背装饰、后摆/披风后片、大蝴蝶结 L/R 单独成层。
- 道具（手持魔杖）与漂浮伙伴、表情特效单独成层。
- 地面阴影单独成层。

整体规则（8 张图共同点）：
1. 每个会动的部位独立成层。
2. 关节两侧都要补图（肩、肘、腕、髋、膝、踝），补图超出的部分被上层遮住。
3. 层序从前到后：前发 → 侧发 → 身体/躯干 → 后发/后摆 → 地面阴影。
4. 眼白作为眼睛底层；高光、瞳孔、睫毛按眼皮遮挡层的顺序叠放。
