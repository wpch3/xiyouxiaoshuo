## 🛠️ 核心功能矩阵

1. **每角色专属动态主题 UI**：
   - 切换不同 AI 角色时，整套 UI 的主色调、背光光晕（Glow）、卡片边框、对话气泡风格均同步平滑切换为对应模型的主题色。
2. **拟人伴侣动态交互**：
   - **呼吸与微动**：待机呼吸律动、眨眼、环状粒子轨道缓慢公转。
   - **摸摸头互动**：点击头部触发开心眨眼与专属好感度台词，并喷洒对应主题色粒子纸屑。
   - **趣味投喂系统**：提供“干净代码零食串”、“万字论文营养便当”、“全栈仓库豪华大餐”等不同食物包，给宠物补充 Token 储备并提升活力。
3. **本机 API 用量仪表盘**：
   - 保存成功调用的 Token 用量和费用记录；优先使用供应商返回的 usage，缺少 usage 时按文本估算并明确标记。费用按角色的本地参考费率计算，不等同于供应商账单或账户余额。
4. **全景功能面板**：
   - **Token 投喂饲育**：挑选数据包补充储备。
   - **模型费率横向对比**：直观展示四大 AI 模型的 Input/Output 费率（如 DeepSeek $0.55/M 到 Claude $3/M 的对比）。
   - **调用流水审计**：显示时间戳、调用任务、Token 用量来源（API 返回或本地估算）以及按参考费率计算的费用。
   - **预算预警与配置**：可自主设定月度支出软上限与预警百分比。
5. **多窗口形态切换**：
   - **完整仪表盘模式**：适合深度查看监控、模型费率与详细流水。
   - **精简桌面宠模式**：收缩为紧凑可爱的桌宠窗口，方便置于桌面角落实时伴读。
6. **API 工作区与本机协作**：
   - 支持官方 API 与 OpenAI-compatible 本地模型；聊天、用量和设置保存在本机。
   - 可把本机资料文件加入 IndexedDB；只有勾选为上下文的文本会在请求时发送到当前 API。
   - Agent 可在桌面版选择工作目录、读取文件、生成结果；写入或运行命令前会显示目标并要求确认。
   - 多角色群聊会按顺序调用角色各自的 API，后续角色可看到之前的回应；多角色调用可能产生多笔费用。
   - 可配置 GitHub、云盘等快捷链接；这里仅保存并打开链接，不会自动登录或同步云端。
7. **语音聊天**：
   - 支持设备语音识别/播报；配置兼容的语音 API 后可使用录音转写和 TTS API。
   - 被勾选的资料与语音音频会发往你所配置的 API；请勿上传不该外传的隐私或密钥内容。

## 🚀 启动与运行

### 本机开发

API 请求由 Python 本机网关转发。先在仓库根目录准备前端构建文件（仅首次或源码更新后需要）：

```bash
cd app
npm ci
npm run build
cd ..
```

在第一个终端启动网关：

```bash
python local_api_server.py --host 127.0.0.1 --port 8765
```

再开第二个终端启动 Vite：

```bash
cd app
npm run dev
```

浏览器访问 Vite 显示的本地地址（默认 `http://localhost:5173`）。不要把本机网关端口暴露到公网。

### Windows 桌面版

运行仓库根目录的 `build_windows_exe.ps1`（PowerShell）或 `build_windows_exe.bat`。桌面入口会自动启动仅监听 loopback 的本机网关，并提供 PyWebView Agent 文件/命令桥接。
