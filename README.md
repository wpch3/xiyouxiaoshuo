# AI Token Pet · 拟人桌面 Token 消费宠物伴侣软件

一款面向 AI 开发者与重度 LLM 用户的桌面宠物应用，将真实 API 调用、费用记录和角色互动整合到一个本机工作台中。

## 当前桌宠阶段

- 以小寻 DeepSeek 形态作为动态立绘样板，新增高清透明背景原画。
- 立绘舞台提供待机呼吸、轻微视线跟随、抚摸反馈和敲击反馈。
- 点选“手抚摸”后，光标移到角色上显示手部图像；按住并拖动可触发连续抚摸效果。
- 点选“小锤子”后，角色区域显示锤子光标；点击立绘会播放锤击动画。
- 角色动作只触发视觉/音效反馈，不插入预设聊天台词；对话气泡显示真实 API 回复或连接状态。
- UI 图形使用角色图片和可缩放矢量图，不使用 Emoji 字符充当图标或道具。
- 现有 7 个角色与 4 种形态继续保留；其余角色与形态的立绘检查、统一重绘及分层素材制作仍在路线图中。

## 已有功能

- 每个角色分别配置模型名称、API Base URL 和 API Key；支持官方接口与 OpenAI-compatible 本地接口。
- 聊天、调用用量、费用参考记录、角色偏好和服饰选择保存在本机。
- 本机资料库可用 IndexedDB 保存文件；明确勾选的文本会在请求时作为上下文发送至当前 API。
- 桌面版 Agent 可在授权工作目录中读取资料；写入文件或运行命令前会显示范围并要求确认。
- 多角色群聊按顺序调用所选角色的 API，可能产生多笔费用。
- 可保存并打开 GitHub、云盘等快捷链接；链接区域不会自动登录或同步云端。
- 当前保留单次语音转文字输入；独立 TTS 播报已移除。真正的电话式实时语音还未接入，须先确认供应商有支持双向实时音频的接口。

## 启动与运行

### 本机开发

API 请求由 Python 本机网关转发。先在仓库根目录准备前端构建文件（首次安装或源码更新后需要）：

```bash
cd app
npm ci
npm run build
cd ..
```

在一个终端启动网关：

```bash
python local_api_server.py --host 127.0.0.1 --port 8765
```

再开第二个终端启动 Vite：

```bash
cd app
npm run dev
```

浏览器访问 Vite 显示的本地地址（默认 `http://localhost:5173`）。不要把本机网关端口暴露到公网。

### Windows 桌面版

运行仓库根目录的 `build_windows_exe.ps1`（PowerShell）或 `build_windows_exe.bat`。桌面入口会启动仅监听 loopback 的本机网关，并提供 PyWebView Agent 文件/命令桥接。桌面持久化修复尚需在目标 Windows 环境重启验证。
